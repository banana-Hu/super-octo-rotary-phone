# 主体组合抠图设计

## 目标

在保留现有逐人抠图的前提下，额外输出可直接放入模板的主体组合图：相互靠近的人保留为一个组合；人物手持、怀抱或紧密连接的前景物体尽量一并保留。

## 范围

- 仅修改 `algorithm/` 下的 Python 图像算法、测试和接入文档。
- 不修改前端，不实现 HTTP 后端，不处理视频，不训练模型。
- 保留 `people/person_*.png`，新增 `subjects/subject_*.png`。
- 不把测试照片、模型权重或第三方源码提交到仓库。

## 处理流程

1. 继续使用 Mask R-CNN 得到最多 5 个独立人物掩膜。
2. 根据人物框的水平距离和垂直重叠关系，将相互靠近的人组成连通分组；距离较远的人保持不同分组。
3. `people` 模式直接合并每组人物掩膜，得到稳定且无需额外依赖的主体图。
4. `foreground` 模式额外调用 InSPyReNet 显著前景模型。算法只保留位于组合附近、并与人物掩膜连通的前景区域，再与人物掩膜取并集；因此可覆盖笔记本、相机等连接物体，同时抑制远处背景。
5. 增强模型不可用或推理失败时，自动回退到人物组合，不影响已有逐人结果，并在 `warnings` 中说明原因。

## 接口与产物

`CutoutOptions.subject_mode` 支持：

- `none`：只输出原有逐人结果。
- `people`：默认值；输出逐人结果和人物组合。
- `foreground`：输出逐人结果和前景增强组合。

`ProcessingResult.subjects` 是兼容新增字段。每个主体记录编号、成员人物编号、模式、处理图坐标、像素面积和相对产物路径。原有字段及含义不变。

## 性能与降级

本地 CPU 实测中，Mask R-CNN 每张约 3–7 秒；InSPyReNet 缓存权重后的模型加载约 5 秒、每张约 9–10 秒。`foreground` 因此只在演示需要保留交互物体时开启。首次使用两种模型都可能下载权重，应在比赛前完成预热。

## 已知边界

- 显著前景模型可以较好保留两人共用的笔记本和手持相机，但不能保证保留所有“正在使用但没有接触”的物体。
- 与人物相连的大面积桌面、包或相似前景可能被多保留；模板侧仍需按主体框缩放和摆放。
- 主体分组是可解释的几何规则，不做人际关系或动作语义判断。

## 验收

- 两个近距离人物生成一个主体，两个远距离人物生成两个主体。
- 逐人 PNG 与主体 PNG 同时存在，均为透明 RGBA。
- 增强掩膜中的人物连接物体被保留；远离人物的前景连通块被排除。
- 增强模型失败时仍返回人物和人物组合，并给出降级告警。
- 原有测试、格式检查、依赖检查和真实图片冒烟测试全部通过。
